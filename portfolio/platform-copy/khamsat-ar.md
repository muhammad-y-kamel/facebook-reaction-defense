# نص معرض أعمال لخمسات

## عنوان مختصر

نظام دفاع ضد إساءة استخدام تفاعلات صفحات فيسبوك

**اسم المشروع الرسمي:** Facebook Page Reaction Abuse Monitoring and Moderation Automation

## وصف المشروع

بنيت وشغّلت نظام مراقبة وأتمتة يستخدم Facebook Graph لاكتشاف منشورات الصفحات وتعليقاتها الاختيارية وتقييماتها. لا يعدد Graph تفاعلات المستخدمين الآخرين لهذا المسار؛ يقرأ Playwright المصرح له متصفح التفاعلات ضمن حدود، ولا يقبل رابط الحساب الرقمي إلا عند تطابق تسمية Angry/Haha وعلامة مصدر الأيقونة. تمنع حالة JSON الذرية تكرار العمل.

يجري وضع الرصد قراءات متصفح من دون تغيير إداري. لا يبدأ الحظر إلا عند `--apply` صراحة، وبعد التحقق من هوية الصفحة الأصلية. مطابقة كلمات التقييمات ترسل تنبيهاً فقط، وTelegram اختياري. تحتاج تسميات mbasic ومحدداته وترقيمه وتوافق التعليقات إلى تحقق حي مصرح به.

## دوري

**مهندس الأتمتة، المطوّر، ومسؤول التشغيل**

> حدّدت المشكلة التشغيلية، وصممت منطق المراقبة والإدارة، وبنيت الأتمتة وتكامل فيسبوك، وهيأت تشغيلها، ونشرتها، واستخدمتها لحماية الصفحات التي كنت مسؤولاً عنها.

## ما يثبته المشروع

- تصميم نظام مراقبة حي لمنشورات الصفحة وتعليقاتها.
- منطق كشف وتصنيف لتفاعلات `ANGRY` و`HAHA`.
- منع تكرار التنفيذ باستخدام حالة JSON ذرية.
- إجراء إداري صريح تحت هوية الصفحة الأصلية.
- تسجيل النتائج والأخطاء مع تنبيهات اختيارية.

## الخدمة التي يدعمها

يدعم هذا المشروع خدمة بناء أتمتة Python مخصصة للرصد القائم على القواعد، وربط API، ومنع تكرار المعالجة، وتنفيذ مسارات متصفح مصرح بها عند الحاجة.

## تعليقات الصور

1. **المراقبة:** اكتشاف عناصر المنشورات والتعليقات عبر Graph، ثم قراءة متصفح التفاعلات عبر Playwright.
2. **القرار:** كشف الحساب، منع التكرار، ثم اختيار وضع `--apply` صراحة.
3. **الإجراء:** التحقق من هوية الصفحة الأصلية قبل المتابعة عبر Playwright.

## حدود العرض

النسخة العامة تستخدم معرّفات اصطناعية ولا تعرض بيانات دخول أو جلسات أو معرّفات حقيقية أو سجلات خاصة. لا أدّعي أن التشغيل الحالي نشط أو أن علامات النقر المحلية تمثل حالات حظر مؤكدة من فيسبوك.
