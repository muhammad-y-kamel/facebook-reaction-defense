# نص مشروع لمنصة أريد — العربية

## عنوان المشروع

أتمتة مراقبة إساءة استخدام تفاعلات صفحات فيسبوك وإدارتها

**اسم المشروع الرسمي:** Facebook Page Reaction Abuse Monitoring and Moderation Automation

## الدور

مهندس الأتمتة، المطوّر، ومسؤول التشغيل

## النبذة

بنيت وشغّلت نظام Python يكتشف منشورات صفحات فيسبوك وتعليقاتها الاختيارية وتقييماتها عبر Graph. يقرأ Playwright المصرح له صفحات متصفح التفاعلات ضمن حدود مضبوطة، ولا يقبل رابط الحساب الرقمي إلا عند تطابق تسمية Angry/Haha وعلامة مصدر الأيقونة المضبوطة. تمنع حالة JSON الذرية تكرار العمل لكل صفحة وحساب. يجري الرصد قراءات متصفح من دون تغيير إداري؛ ويفعّل `--apply` مسار الحظر المنضبط. تنبيهات التقييمات فقط، وTelegram اختياري. تحتاج تسميات mbasic وعلامات الأيقونات ومحدداته وترقيمه وتوافق التعليقات إلى تحقق حي مصرح به.

> حدّدت المشكلة التشغيلية، وصممت منطق المراقبة والإدارة، وبنيت الأتمتة وتكامل فيسبوك، وهيأت تشغيلها، ونشرتها، واستخدمتها لحماية الصفحات التي كنت مسؤولاً عنها.

## التقنيات

Python، Facebook Graph API، Playwright، حالة JSON ذرية، Telegram اختياري

## خمس مهارات

- أتمتة Python
- تكامل واجهات API
- أتمتة المتصفح
- منطق كشف قائم على القواعد
- تصميم مسارات التشغيل

## النتيجة الموثقة

شغّلت تهيئتي التاريخية عمليتي استطلاع للصفحات بفاصل ثماني ثوانٍ. تحتوي سجلات التشغيل الخاصة على 28 رابط منشور فريداً و210 سلاسل روابط حسابات فريدة في الطوابير؛ ولا يتوفر عدد حظر أكدته المنصة.

## حدود العرض العام

يستخدم المستودع تهيئة منزوعة البيانات الخاصة ومعرّفات اصطناعية. لا يتضمن رموز الوصول أو جلسات المتصفح أو معرّفات الصفحات والحسابات أو الروابط الخاصة أو السجلات الأصلية. لا أدّعي أن التشغيل الحالي نشط، ولا أضمن نتائج تؤكدها المنصة من دون تحقق حي مصرح به.
