## Title

Facebook Page Reaction Abuse Monitoring and Moderation Automation

## Role

Automation Architect, Developer and Operations Owner

## Description

I built a Page automation where Graph discovers posts, comments, and ratings; authenticated Playwright requires a label and icon-source marker match before accepting numeric profiles. Atomic JSON state prevents duplicate Page/account work. Detection makes browser reads but no moderation mutation; explicit `--apply` enables the fail-closed Page block path. Rating keywords alert only. Current mbasic matchers, pagination, selectors, and comment compatibility need authorized live checks. I deployed and operated the original system; no active deployment or provider-confirmed result is claimed.

## Authorship line
